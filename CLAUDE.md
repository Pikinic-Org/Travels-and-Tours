# Travel & Tours — Pikinic

This is the **Travel & Tours** subdomain site for Pikinic (`travelsandtours.pikinic.ng`) — a sibling site to the main marketing site at `pikinic.ng`. It is its own separate codebase/project, not a page inside the main site.

@design.md

The file imported above is the design system extracted from the main Pikinic site: exact color values, typography, layout/spacing rhythm, the motion system, brand motifs (the pathway ribbon mark and the square-frame grid), core components (buttons, bordered-grid patterns, nav patterns), page composition patterns, and content rules (no fabricated copy, stats, or team members). It exists specifically so every sibling site — Study Abroad, Travel & Tours, Stay & Ride, Finance — shares one consistent visual identity with the main site.

Treat `design.md` as binding. Match it exactly rather than inventing a new visual language, unless explicitly told to deviate.
