# Travel & Tours — Pikinic

This is the **Travel & Tours** subdomain site for Pikinic (`travelsandtours.pikinic.ng`) — a sibling site to the main marketing site at `pikinic.ng`. It is its own separate codebase/project, not a page inside the main site.

@design.md

The file imported above is the design system shared with the main Pikinic site: exact color values, the Grift and Nexa typefaces, spacing and radius, the motion rules, the brand pattern, core components (the button, cards, deep-green blocks), page patterns, and content rules (sentence case, no fabricated copy, stats, or team members), plus a section on what is specific to Travel & Tours. It exists specifically so every sibling site — Study Abroad, Travel & Tours, Stay & Ride, Finance — shares one consistent visual identity with the main site.

Treat `design.md` as binding. Match it exactly rather than inventing a new visual language, unless explicitly told to deviate.
